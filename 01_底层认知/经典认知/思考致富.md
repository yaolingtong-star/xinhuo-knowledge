# 思考致富 · 拿破仑·希尔

> 只要你想得到，你就一定能够得到的

## 基本信息

- 作者：拿破仑·希尔（1883-1969）
- 年代：1937年出版
- 结构：15个成功法则
- 核心理念：欲望、信念、行动、毅力、智囊团

---

## 核心理念

### 心想事成（第一章）

> 心中的想法会化为行动。只要你想得到，你就一定能够得到的。

*所有成就的起点是强烈的欲望，欲望必须坚定、具体、可实现。*

### 十三项成功原则

| 原则 | 说明 |
|------|------|
| 欲望 | 确切的渴望，想象最想要的结果 |
| 信念 | 相信自己能实现，相信吸引力法则 |
| 专业知识 | 专门知识+想象力，综合创造财富 |
| 想象力 | 主动创造和整合想法的能力 |
| 计划 | 将想法转化为行动方案 |
| 决策 | 果断决策，不拖延 |
| 毅力 | 坚持不懈，直至成功 |
| 智囊团 | 高质量的外部力量支持 |
| 性的能量 | 将性能量转化为创造力 |
| 潜意识 | 潜意识是信念与欲望的连接点 |
| 头脑 | 创造性合作的智慧 |
| 第六感 | 直觉，获得创造性想法 |
| 付出 | 付出是收获的前提 |

## 核心方法

### 明确目标
1. 在纸上写下确切的金额
2. 写下获得这笔钱的时间期限
3. 写下明确的计划
4. 每天朗读这个计划两次

### 吸引力法则
- 同类相吸：你的想法会吸引相同频率的人和事
- 专注会放大吸引力
- 潜意识是媒介
